# 论文回收站

已有数据库先执行 `sql/migrate_paper_recycle.sql`，然后重启后端；新数据库使用 `sql/create_table.sql`。

- `POST /paper/recycle`：`{"id":"论文ID","isRecycled":1}` 回收，0 恢复。仅本人可操作，可重复调用。
- `POST /paper/list/page`：新增 `isRecycled`（0/1），省略默认为 0；1 查询回收站。仍按本人、未逻辑删除过滤。
- 论文摘要和详情返回 `isRecycled`。回收不修改 `is_delete`，不清理文件、索引、任务、笔记、会话和引用。
- `POST /paper/add` 保留哈希去重及唯一索引。正常重复返回已有记录并标记 `alreadyExists=true`；已回收重复返回业务码 40900，提示恢复。
- 新增/恢复会话关联禁止回收论文；全量范围更新允许保留已有回收论文，仍校验归属。论文行锁串行化新增关联和回收操作。
- `/library` 右上角回收站入口；`/library?view=recycle` 支持恢复。会话选择器默认查询正常论文，详情页对回收论文隐藏加入会话按钮。
- 旧会话顶部展示回收提示及论文名单，仍可提问和查看引用。进入会话、刷新资料、窗口重新获得焦点时刷新论文状态。
- 不提供彻底删除。
