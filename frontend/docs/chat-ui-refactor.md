## 交互约定

- 会话内只有消息区滚动，输入区作为独立 flex 区域固定在底部，不绝对覆盖消息；多行输入随草稿自动扩展并设置高度上限。
- RAG / Agent 选择、PDF 上传和发送/停止位于输入框工具栏。模式说明通过帮助按钮打开；快捷问题只在没有消息和任务的新会话中展示。
- 草稿仍使用原有自动保存、离开前保存和失败保护，正常保存状态不再常驻，仅失败时提供提示与重试。
- 点击顶部论文数量查看当前资料及阅读入口；「调整资料」仍复用 ScopeManager 的完整集合提交、版本冲突、跨页选择和空范围流程。
- 执行摘要在运行时显示当前阶段与恢复连接状态；展开后显示技能、工具、耗时、错误码及未确认结果。终态收起后可再次展开。
- 会话重命名、导出与删除位于右上角「…」中；切换会话、创建会话仍直接可达。
- 导航偏好仅保存一个本地界面布尔值，不把聊天、论文或执行状态迁移到本地存储。

## 业务边界

未修改后端文件、API 模块、请求参数、响应类型、Pinia 业务状态、`useChat.ts`、`runObserver.ts` 或 SSE 事件协议。幂等重试、事件补发、快照/轮询恢复、取消任务、历史加载及资料校验均沿用原实现。

正式页面不引用测试数据。浏览器夹具仅位于测试目录，发送具名 SSE 的用例使用浏览器原生 EventSource。它验证现有事件协议，没有新增后端不支持的 token 流式协议或虚构消息。
