# 比较输出模板
沿用系统 JSON 协议，以下 Markdown 内容放在 answer 字符串中，外层只保留 answer 与 evidenceIds。

## 比较范围与问题
列出本次所有论文、用户关注的维度和基于检索片段的限制。

## 证据覆盖矩阵
每行一篇论文，每列一个比较维度；单元格为“已覆盖/部分覆盖 + 实际引用标记”或“未找到证据”。不得用其他论文的证据填补该篇缺口。

## 分维度比较
用表格对照研究问题、方法、创新、实验设置、结果、局限；事实旁附对应引用。用户指定维度时优先展开指定维度。

## 综合分析与覆盖缺口
归纳共性、差异、适用条件和实验可比性。区分原文结论与基于证据的推测，逐项列出未覆盖内容，不给出缺乏依据的优劣排名。

所有引用用系统提供的 [E1] 形式逐个标记，evidenceIds 与 answer 实际引用集合完全一致，不输出占位引用。
