# 研究分析输出模板
沿用系统 JSON 协议，以下内容放入 answer 字符串，外层仍为 answer 和 evidenceIds。

1. 分析主题与资料范围：列出论文和覆盖情况，说明仅基于检索片段。
2. 已有研究与局限：逐项区分作者结论、作者局限、系统推测；原文事实附实际证据引用。
3. 候选研究方向：每个方向包含研究问题、意义、相关论文依据、简要推导理由、可验证假设、建议实验、对照、评价指标、失败条件。
4. 证据缺口与待补充检索：说明未覆盖论文、缺失证据、待调查的外部相关工作和不确定性。

候选方向属于待验证建议，不是已证实的创新。建议的实验设置和指标必须标注为建议，不能伪装成原文已有实验。
引用仅使用成功工具结果的证据 ID，正文逐个写 [E1] 形式的标记；evidenceIds 与实际引用集合完全一致，无证据时不编造引用。
